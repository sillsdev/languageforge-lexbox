Lexbox logo

A wooden crate with a blue side carrying the Thai letter ล and a rack of four word tiles; the blue tile with the folded corner is the word. This page tells you which file to use where, and every file can be downloaded from it.

Which file do I need?

The logo is drawn three times, from detailed to simple. Pick the drawing by the size it will appear at on screen; the same files go on dark grounds.

The three drawings

Every icon below is shown at its real size in screen pixels. Smaller drawings thicken the outlines and widen the gaps between the tiles. Below 40 px they also drop the marks on the tiles, the folded corner and the lid's cross-boards, keeping three boards.

Why not just shrink the big one?

Below, each icon is drawn into real pixels at 24 and 16 px, then enlarged so you can see the pixels. The full drawing's outlines and the marks on its tiles need 96 px. Below that each size range gets its own drawing of the same crate.

Do and don't

  • Use the file made for the size: the full drawing from 96 px, small 40 to 95, tiny 16 to 39.
  • Use the same files on light and dark grounds, dark mode included: there is no dark version.
  • Leave a little room round the mark, about a sixth of its width: the files themselves have only 2% padding.
  • Use the SVG wherever it is accepted.
  • Don't shrink the full drawing below 96 px.
  • Don't recolour the tiles or the crate, and don't add outlines, shadows or effects.
  • Don't cut the one-colour logo in vinyl or embroider it smaller than 45 mm wide; its thin lines won't hold.
  • Don't go below 16 px.
  • Don't redraw it from a screenshot. Download the file.
