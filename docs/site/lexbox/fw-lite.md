[FieldWorks Lite](/fw-lite/) lets team members do dictionary work on a phone, tablet or
computer while the rest of the team keeps using FieldWorks. This page is for the project
manager who turns it on. FieldWorks Lite is still being developed
([what that means](/fw-lite/faq#is-fieldworks-lite-finished)).

## Before you start

- **Your FieldWorks project is on Lexbox and has data.** A new project stays empty until
  someone sends it from FieldWorks for the first time
  ([Fill it with data](/lexbox/host-a-project#fill-it-with-data)), so even a team that will
  only use FieldWorks Lite needs FieldWorks once to start. No project on Lexbox yet? See
  [Host a project](/lexbox/host-a-project).
- **You are a Manager of the project** ([roles](/lexbox/manage-members#roles)).
- **Everyone who uses FieldWorks on the project has done a Send/Receive.** Lexbox then has
  everyone's latest work before it makes the FieldWorks Lite copy, and that is the point
  Lexbox can go back to if something goes wrong.

## Turn it on for your project

1. Open your project's page on lexbox.org and choose **Try FieldWorks Lite?**.
2. Confirm with **Yes, please!**.

Lexbox prepares a FieldWorks Lite copy of your project. This can take a while, longer for
a large project. It runs on Lexbox, so you can leave the page while you wait.
When it's done, the project carries a **Using FieldWorks Lite** badge; refresh the page if
you don't see it yet.

If the project has no data yet, the dialog says so instead of offering **Yes, please!**.
If you aren't a Manager, **Yes, please!** is greyed out.

## If you don't see the button

The button only appears on FieldWorks projects.

:::info[While FieldWorks Lite is in beta]
Only managers with early access see the button. You can request it on the
[Where's my project?](https://lexbox.org/wheresMyProject) page. If we told you that you
have early access but you still don't see the button, we may have given access to a
different account: write to
[lexbox_support@groups.sil.org](mailto:lexbox_support@groups.sil.org) with the email
address or login you use.
:::

## Give your team access

Add each person on the project page as usual ([Add people](/lexbox/manage-members#add-people)),
with the **Editor** role for people who will edit. Then send them
[Getting started](/fw-lite/getting-started): it covers installing the app, logging in and
downloading the project. For team members without an email address, see
[People without an email address](/lexbox/manage-members#people-without-an-email-address).

## Keep the two sides in step

FieldWorks Lite users don't need to do anything. If some of the team still uses FieldWorks,
make this part of the team's rhythm:

1. FieldWorks users **Send/Receive** as usual.
2. An Editor or Manager presses **Sync** on the **Lexbox** tab in FieldWorks Lite (or
   **Sync FieldWorks Lite** on the project page). Once started, it runs on Lexbox, so you
   can close the app or the page.
3. FieldWorks users **Send/Receive** again to pick up the FieldWorks Lite work.

[How sync works](/fw-lite/how-sync-works) shows why each step is needed.

### Before big changes in FieldWorks

Some changes in FieldWorks, such as adding a custom field, ask everyone on the team to
Send/Receive first. Count FieldWorks Lite as one more team member: do steps 1 to 3 above,
make the change, then do steps 1 to 3 again.

## If something goes wrong

See [Something is missing or wrong in my project](/fw-lite/faq#something-is-missing-or-wrong-in-my-project)
and [How do I report a problem?](/fw-lite/faq#how-do-i-report-a-problem-or-ask-for-help).
Please tell support that you are using FieldWorks Lite.
