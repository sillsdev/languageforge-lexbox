A project on Lexbox gives your team one shared home for its data: everyone uses
Send/Receive with it, and you manage the member list on the website.

## Ask for a project

On **My Projects**, choose **Create Project** (you need a verified email address to see
it). The form asks for:

- **Name**: usually the name of the language you are working on.
- **Project type**: FieldWorks, WeSay (LIFT), OneStory Editor, OurWord or Adapt It.
- **Organization**: the [organization](/lexbox/organizations) the project belongs to, if
  any.
- **Purpose**: **Language Project** for real work, or **Training**/**Testing** for practice
  projects. The form starts on Training, so change it for a real project.
- **Language Code**: preferably the [Ethnologue code](https://www.ethnologue.com/) of the
  language.
- **Description**, and whether the project is **confidential** (see
  [Members and roles](/lexbox/manage-members#confidential-projects)).

Lexbox builds the project **code** from your answers, and it can't be changed later: for
example `qaa-flex` for a FieldWorks Language Project on language `qaa`, or
`qaa-train-flex` for a Training one. If similar projects already exist in the organization
you selected, the form shows them and offers **Ask to join** instead, so teams don't split
their work by accident.

## Approval

If you manage (or have managed) a project on Lexbox, the form's last button reads
**Create Project** and the project is created right away. Otherwise it reads **Request
Project**: the project shows up under My Projects marked **Awaiting approval**, an
administrator reviews the request, and you get an email when it is approved.

## Fill it with data

A new project starts empty. Put your data in with your program's first Send/Receive. In
FieldWorks that is **Send/Receive** → **Send this Project for the first time**. The
project's page on lexbox.org shows these steps under **Set up project**, with your login
and project code already filled in. See [Send/Receive](/lexbox/send-receive/).
