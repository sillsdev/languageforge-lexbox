**Send/Receive** is how desktop programs exchange work with Lexbox: it uploads your
changes and downloads your colleagues', merging the two. You run it from inside your
program (FieldWorks, WeSay, OneStory Editor, OurWord or Adapt It), not from the website.

You need three things:

- your Lexbox **login** (your email address, or an old Send/Receive login) and
  **password**;
- to be a **member** of the project, as an Editor or Manager (see
  [Members and roles](/lexbox/manage-members));
- the **project code**, shown on the project's page on lexbox.org (for example
  `qaa-flex`).

The easiest path starts on your project's page on lexbox.org. For a FieldWorks project,
choose **Open with FieldWorks** (FieldWorks 9.2 or later): your browser hands the project
to FieldWorks, and the same box lists the manual steps with your login and project code
filled in. For other programs, choose **Get project**. A project with no data yet shows
**Set up project** instead.

## FieldWorks

To get a project onto your computer by hand:

1. In FieldWorks, choose **Send/Receive** → **Get Project from colleague…**.
2. In the **Receive project** box, choose **Internet**.
3. Enter your login and password and choose **Log in**.
4. In the **Project ID** list, pick your project code.
5. Type a **Name for the folder on your computer** (the project code works well).

After that, **Send/Receive** in FieldWorks syncs the project whenever you choose. For how
Send/Receive itself works (merging, conflict notes, good habits), see the
[FieldWorks help on Send/Receive](https://software.sil.org/fieldworks/help/using-sendreceive/).

## WeSay

In the **WeSay Configuration Tool**, choose **Get from Internet** and set **Server** to
**Custom Location...**. Then open **Get project** on your project's page on lexbox.org,
type your password, and copy the **Send/Receive URL** it builds into WeSay's URL box. The
URL already contains your login and the project code.

## If your team also uses FieldWorks Lite

FieldWorks Lite work reaches Send/Receive only after someone presses **Sync** on the
**Lexbox** tab in FieldWorks Lite (people in the FieldWorks Lite beta also have **Sync FieldWorks Lite** on
the project page). If a colleague's FieldWorks Lite changes are missing after your
Send/Receive, ask for a Sync, then run Send/Receive again. See [Keep the two sides in step](/lexbox/fw-lite#keep-the-two-sides-in-step).

## Slow or unreliable internet?

Send/Receive is built for bad connections and can pick up where it left off, so a large
project can arrive over several attempts. If your team is stuck, write to
[lexbox_support@groups.sil.org](mailto:lexbox_support@groups.sil.org).
