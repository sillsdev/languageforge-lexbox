Every project has a member list, managed on the project's page on lexbox.org. Members log
in with their own accounts. Teams should not share one login.

## Roles

| Role | lexbox.org | FieldWorks Send/Receive | FieldWorks Lite |
| --- | --- | --- | --- |
| **Manager** | See the project; manage members, name, description and settings | Yes | Edit and comment |
| **Editor** | See the project and its members | Yes | Edit and comment |
| **Commenter** | See the project and its members | No | View and comment, no editing |
| **Viewer** | See the project and its members | No | View only |

Commenter and Viewer are **FieldWorks Lite only** roles. They're offered only on projects
that use FieldWorks Lite, and people with them can't Send/Receive from FieldWorks. A
Commenter can start comments, reply, and change or delete their own comments. Resolving
or reopening a comment needs an Editor or Manager.

## Add people

As a manager, use **Add/Invite Member** on the project page: enter the person's email
address (or old Send/Receive login) and pick a role. If they don't have an account yet,
tick **Invite**. They get an invitation email with a **Join Project** button, which
expires after 3 days.

Adding a whole class or workshop at once (a list of logins or emails and a shared
password, creating missing accounts) uses **Bulk Add/Create Members**, which only Lexbox
administrators see. Write to [admin@languagedepot.org](mailto:admin@languagedepot.org) to
have it done.

Members of an organization that owns your project can also find it themselves and choose
**Ask to join project**, if it is marked not confidential. You get an email with an
**Approve Request** button, which opens the add dialog with their name filled in: pick a
role and choose **Add Member**.

Each member's menu lets you **Change Role** or **Remove** them. Anyone can leave a project
themselves (**Leave Project**, under **More settings**), except the last manager, who must
first hand the project to someone else.

## Confidential projects

A manager can mark a project as confidential (**More settings** → **Set project
confidentiality**). On a confidential project, only managers see the member list, and the project is hidden from
people who aren't members. Organization members can only find projects that are marked
*not* confidential, so set it either way.

## Project history

The project page shows the changes sent to Lexbox (choose **Show history**): when, by whom,
and the message their program attached. **Open in HgWeb** shows the complete history.

## Delete a project

Managers can delete a project under **More settings** → **Delete Project**. This deletes
it on Lexbox for everyone. To take a project off your own phone or computer in FieldWorks
Lite, [delete it there instead](/fw-lite/faq#how-do-i-remove-a-project-from-my-device).
